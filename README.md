Este es un simple scrapping que se conecta a la web del portal de mi
ex universidad. 

Implementé una herramienta llamada sonarqube que escuché en una entrevista de trabajo, 
lo configuré con una instancia de docker para agarrarle el pedo y lanzó esto:

una extensión de vue js solo para "aplicar lo que en vue es correcto". Despues eso provocó
incidencias en los sistemas porque los == los pasaba a === y no era adaptable en x función.

Una herramienta interesante que hay que usar con cuidado.
